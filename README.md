# 一周计划

适合手机使用的周计划与备忘录，纯静态 HTML，无需安装依赖。

- 调整任务、时间和星期，标记完成或跳过。
- 课程与恢复时段默认固定，批量调整会保留它们。
- 备忘录支持随手记、编辑、搜索、分类、置顶、完成和回收站。
- 记录每日睡眠、精力和复盘。
- 29 项选填日记录支持草稿暂存、提交保存、按日期修改和历史查看。
- 用已提交记录查看趋势和睡眠 / 精力散点；空白不按零统计。
- 可导出 Markdown 反馈报告和 CSV 日记录，方便之后反馈给 AI。
- 34 个主题、687 条每日 tips 摘录自《高性价比人生指南》，支持手动“换一换”，刷新保留至下次每日更新；每条带原文链接与说明，详见 [ATTRIBUTION.md](ATTRIBUTION.md)。
- 导出 / 导入 JSON 备份，也能下载包含当前数据的 HTML。

所有填写内容保存在当前设备浏览器的 localStorage。GitHub Pages 仅托管网页，手机和电脑的数据不会自动同步。更换设备时，请导出备份后导入；清理浏览器数据前先备份。

Tips 按北京时间（Asia/Shanghai）每天 12:30 轮换。页面打开时自动切换；关闭期间，下次打开会显示当期内容，不发送系统推送。建议库为固定版本，日轮换不等于每天抓取原项目的新内容。

提交日记录后才进入图表与反馈报告。再次提交同一日期会更新该日记录；未提交草稿可恢复但不计入统计。记录范围截至北京时间今天。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。

首页为 `index.html`，`.nojekyll` 用于直接发布静态文件。

手机浏览器打开发布地址后，可通过浏览器菜单添加到主屏幕。网页需要首次加载后才能使用，不提供离线缓存或系统推送提醒。
